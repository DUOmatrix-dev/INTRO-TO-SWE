Introduction to Software Engineering (INTRO-TO-SWE)
A collaborative repository for practical exercises, assignments, and group projects completed as part of our Computer Science coursework.
About
This repository documents our learning and practical application of core Software Engineering and Computer Science concepts. Work may include system analysis and design, UML modelling, software development exercises, and related coursework.
Current Assignment: University Course Registration System
This group assignment models a university course registration system using Unified Modeling Language (UML) diagrams.
Diagrams
- Use Case Diagram — identifies the system actors and the main functions available.
- Class Diagram — represents the main classes, their attributes, operations, and relationships.
- Sequence Diagram — illustrates the interactions involved in a course registration request, including validation and database communication.
- Activity Diagram — describes the registration workflow, validation decisions, and success or failure paths.
Tools
- diagrams.net (Draw.io) — creating and editing UML diagrams
- GitHub — version control, collaboration, and sharing project files
